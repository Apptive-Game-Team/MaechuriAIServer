### Fields to Generate (ALL are required)

1. world_detail (WorldContextSchema)
- visibility_rules: List of objects with "from" (location), "can_see" (list), "cannot_see" (list).
- access_rules: List of objects with "location", "requires" (role/key).
- evidence_types: List of strings (e.g., "fingerprint", "footprint").

2. ground_truth_detail (GroundTruthSchema)
- culprit_ids: List of strings (names/IDs of culprits).
- method: String describing the exact method of the crime.
- required_evidence: List of objects with "type" (string), "min_count" (int).

3. generation_targets (GenerationTargetsSchema)
- suspects: Object with:
    - count: int (number of suspects to generate)
    - roles: List of strings (e.g., "victim", "witness")
    - allow_lying: bool
    - liar_ratio: float (0.0 to 1.0)
- evidence: Object with:
    - count_range: [min, max]
    - ambiguity_level: "low", "medium", or "high"

4. constraints (ConstraintsSchema)
- no_supernatural: bool (usually true)
- no_time_travel: bool (usually true)
- at_least_one_uncertain_alibi: bool
